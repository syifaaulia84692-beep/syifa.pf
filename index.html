Cara menambahkan sertifikat (klik untuk panduan)

GitHub Pages menampilkan file statis, jadi sertifikat ditambahkan dengan mengedit index.html. Simpan gambar sertifikat di repository, misalnya di images/sertifikat-html.jpg, lalu ganti satu kartu placeholder dengan contoh ini. Ubah nama, penyelenggara, dan tanggal sesuai sertifikat asli. Untuk sertifikat berikutnya, duplikat blok <article> ini.

<article class="certificate-card">
  <img class="certificate-image"
       src="images/sertifikat-html.jpg"
       alt="Sertifikat pelatihan HTML">
  <h3>Dasar-Dasar HTML</h3>
  <p>Penyelenggara: Nama penyelenggara</p>
  <p class="certificate-date">Bulan Tahun</p>
</article>

Setelah menyimpan perubahan dan mengunggahnya ke GitHub, sertifikat akan muncul di halaman publik.
